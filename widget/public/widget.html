🤖 AI Query Widget

Universal, plug-and-play AI insights for any website

📦 Integration (ONE Script Tag)

<script src="ai-widget.js" data-api-base-url="http://localhost:5000" data-api-key="demo_api_key_12345" data-tenant-id="11111111-1111-1111-1111-111111111111" data-user-role="Admin" data-position="bottom-right" data-theme="light" data-auto-open="false"> </script>

✨ Features

🚀 Zero Dependencies

Works with React, Angular, Vue, WordPress, or plain HTML. No framework required.

🎨 Fully Isolated

Uses Shadow DOM to prevent CSS/JS conflicts with your existing site.

⚡ Lazy Loaded

Lightweight loader (<5KB) with async bundle loading for fast page loads.

🤖 AI-Powered

Auto-generates insights: risks, opportunities, and actionable recommendations.

💬 Natural Language

Ask questions in plain English. No SQL or technical knowledge needed.

📱 Mobile Ready

Fully responsive design works perfectly on mobile and desktop.

⚙️ Configuration Options

data-api-base-url (required) Your API endpoint data-api-key (required) Tenant API key data-tenant-id (required) Tenant UUID data-user-role (optional) User role (default: "User") data-theme (optional) "light" or "dark" (default: "light") data-position (optional) Widget position (default: "bottom-right") Options: bottom-right, bottom-left, top-right, top-left data-expand-url (optional) URL for "Explore deeper" CTA data-auto-open (optional) Auto-open on load (default: "false")
👈 Look at the bottom-right corner!
The AI widget should be floating there. Click it to see AI-powered insights about your business.

🏗️ Build & Deploy

# Install dependencies npm install # Development mode (http://localhost:3001) npm run dev # Production build npm run build # Output: # dist/ai-widget.js (Loader script ~ 5KB) # dist/widget-app.js (React app bundle) # dist/vendors.js (React + dependencies)

📤 CDN Deployment

# Upload to your CDN: dist/ai-widget.js dist/widget-app.js dist/vendors.js # Update integration: <script src="https://cdn.yourdomain.com/ai-widget.js" data-api-base-url="https://api.yourdomain.com" data-api-key="your_production_key"> </script>
